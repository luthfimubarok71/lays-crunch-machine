# Checklist presentasi klien

## Sebelum presentasi

- Jalankan build terbaru dengan `npm run start`.
- Gunakan tab browser yang sama untuk kiosk dan dashboard agar riwayat sesi dibagikan.
- Untuk QR, buka aplikasi melalui IP LAN yang dapat diakses ponsel atau URL staging yang sudah disetujui.
- Jelaskan label Demo, identitas sintetis, dan aset provisional.

## Urutan presentasi

1. Landing: tunjukkan pilihan skenario dan visual kampanye.
2. Pilih skenario menang → Start → Welcome → Registrasi contoh.
3. Pilih identitas, setujui consent contoh, lalu mainkan video tutorial placeholder.
4. Persiapan menunjukkan preview simulasi tanpa prompt kamera/mikrofon.
5. Mulai countdown; tunggu challenge simulasi 10 detik.
6. Tunjukkan skor 92 dan hadiah ilustrasi.
7. Buka QR dari ponsel: hasil tetap, video contoh, download, instruksi sosial.
8. Lanjut ke share → Thank You → Finish. Pastikan kembali ke landing.
9. Dashboard: peserta baru terlihat, buka detail, putar/pause/replay dan unduh video.
10. Cari peserta, filter, export CSV; tunjukkan preview email.
11. Ulangi dengan skenario no-win (64), pending (88), dan invalid.
12. Pada invalid, demonstrasikan retry tanpa registrasi duplikat.

## Penjelasan batas

- Skor, waveform, hadiah, status email dan video pending adalah fixture.
- Video adalah clip tipografi sintetis, bukan rekaman peserta.
- Tidak ada login admin nyata, pengiriman email, hadiah asli atau backend.
- Demo tidak membuktikan kompatibilitas hardware event atau ketepatan pengukuran suara.
- Copy Instagram belum merupakan aturan kampanye resmi; tombol copy tidak mempublikasikan atau memverifikasi posting.

## Bukti visual

Screenshot pengujian browser tersedia pada folder `screenshots/`. Gambar desktop/tablet/mobile merupakan viewport browser otomatis, bukan foto tablet/ponsel acara.
